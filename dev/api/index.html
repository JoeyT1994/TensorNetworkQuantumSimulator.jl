TensorNetworkQuantumSimulator.TensorNetworkState — Type
TensorNetworkState{V} <: AbstractTensorNetwork{V}

A tensor network state defined on a graph with vertices of type V. Wraps a TensorNetwork together with a dictionary of site indices (physical degrees of freedom) at each vertex.

Fields

  • tensornetwork::TensorNetwork{V}: The underlying tensor network.
  • siteinds::Dictionary{V, Vector{Index}}: A dictionary mapping each vertex to its physical (site) indices.

Construct a TensorNetworkState on graph g where the function f maps vertices to local states. The local states can be given as strings (e.g. "↑", "↓", "0", "1") or as vectors of numbers (e.g. [1,0], [0,1]).

TensorNetworkQuantumSimulator.toriccode_groundstate — Function
toriccode_groundstate(n::Int, s::Dictionary = siteinds("S=1/2", named_grid((n, n); periodic = true)))

Construct an exact bond-dimension-2 tensor network state for the ground state of Kitaev's toric code on an n × n torus. The state lives on a periodic n × n square lattice with one S=1/2 site per vertex.

If passing your own siteinds, they must have a single qubit index per vertex of a periodic n × n named grid.

Arguments

  • n: linear size of the torus (so the lattice has n^2 sites).
  • s: site indices keyed by vertex of the periodic grid. Defaults to a fresh S=1/2 site for each vertex.

Returns a TensorNetworkState of bond dimension 2.

Classical Partition Functions

TensorNetworkQuantumSimulator.ising_partitionfunction — Function
ising_partitionfunction(g::NamedGraph, β::Real; Js::Dictionary = Dictionary(edges(g), [1.0 for e in edges(g)]))

Construct a bond-dimension-2 tensor network whose full contraction equals the partition function $Z(β) = \sum_{\{σ\}} \exp(β \sum_{(u, v)} J_{uv} σ_u σ_v)$ of the classical Ising model on graph g at inverse temperature β.

Arguments

  • g: lattice graph. One tensor is placed per vertex.
  • β: inverse temperature.

Keyword Arguments

  • Js: dictionary of edge couplings, keyed by edges(g). Defaults to uniform ferromagnetic couplings (J_e = 1.0 on every edge). The tensors are complex, so negative (antiferromagnetic) couplings, whose Boltzmann weight has no real symmetric square root, are supported.

Returns a TensorNetwork (not a TensorNetworkState); contract it to obtain $Z(β)$.

TensorNetworkQuantumSimulator.simple_update — Function
simple_update(o, ψ⃗; envs, normalize_tensors = true, sqrt_cutoff, apply_kwargs...)

Simple update of one or two local tensors in the presence of factorized environments under the action of a one- or two-site gate. This is a computationally cheaper but less accurate alternative to full_update. It is exact if no truncation is performed.

Arguments

  • o::Tensor: The gate to be applied.
  • ψ⃗::Vector{<:Tensor}: The one or two local tensors being updated.
  • envs::Vector{Tensor}: The factorized environment tensors associated with the tensors in ψ⃗.

Keyword Arguments

  • normalize_tensors::Bool: Whether to normalize the updated tensors. Default is true.
  • sqrt_cutoff: Cutoff below which environment eigenvalues are treated as zero when forming their (inverse) square roots. Defaults to 10 * eps(real(scalartype(first(ψ⃗)))).
  • apply_kwargs...: Additional keyword arguments passed to the SVD factorization.

Returns

  • updated_tensors::Vector{Tensor}: The updated tensors after applying the gate.
  • s_values::Union{Nothing, Tensor}: The singular values from the SVD (if applicable).
  • err::Number: The truncation error from the SVD (if applicable).

TensorNetworkQuantumSimulator.circuit_from_qasm — Function
circuit_from_qasm(qasm; qubits = nothing)

Import an OpenQASM 2 program for apply_gates, e.g. one written by qiskit's qasm2.dumps(circuit). Gates are looked up by their qiskit names in the gate registry; gates defined in the program (gate name(params) args { ... }) that the registry does not know are expanded from their definitions. Barriers and measurements at the end of the circuit are dropped.

Build the graph from the circuit with build_graph_from_circuit, or simulate on a graph of your own by passing the vertex of each qubit as qubits; two-qubit gates must then act on neighbouring vertices (transpile the circuit onto the graph's connectivity first).

Arguments

  • qasm::AbstractString: The program text (use read(path, String) for a file).

Keyword Arguments

  • qubits = nothing: The vertex of each qubit, in the order the qubits are declared (across qregs). Defaults to the qubit numbers 1, 2, ....

Returns

  • A Circuit with all declared qubits and the imported gates.

Gates on three or more qubits, resets, classically controlled gates and gates after a measurement are not supported; decompose such circuits first (e.g. qiskit's transpile with one- and two-qubit basis_gates).

Example

circuit = circuit_from_qasm("""
    OPENQASM 2.0;
    include "qelib1.inc";
    qreg q[3];
    h q[0];
    cx q[0], q[1];
    rz(pi/4) q[2];
""")
g = build_graph_from_circuit(circuit)
ψ, errors = apply_gates(circuit, tensornetworkstate(v -> "↑", g))
source
TensorNetworkQuantumSimulator.circuit_from_qiskit — Function
circuit_from_qiskit(qc::Qiskit.QuantumCircuit; qubits = nothing)

Import a Qiskit.jl circuit for apply_gates. Available once Qiskit.jl is loaded (using Qiskit); for circuits built in Python, export them with qasm2.dumps and use circuit_from_qasm.

Every one- and two-qubit qiskit standard gate is supported. Barriers, delays, the global phase and measurements at the end of the circuit are dropped. Build the graph from the circuit with build_graph_from_circuit, or pass the vertex of each qubit as qubits; two-qubit gates must then act on neighbouring vertices.

Gates on three or more qubits, unitary instructions, resets and gates after a measurement are not supported; transpile such circuits to one- and two-qubit basis gates first.

Keyword Arguments

  • qubits = nothing: The vertex of each qubit, in order. Defaults to the qubit numbers 1, 2, ....

Returns

  • A Circuit with all declared qubits and the imported gates.

Compute the expectation value of one or more observables on a tensor network state.

  • cache_update_kwargs...: Keyword arguments passed to the update function when using "bp", "boundarymps" or "ctmrg".

Returns

  • A single number if measuring one observable, or a vector of numbers if measuring multiple observables.

TensorNetworkQuantumSimulator.TensorInterface.inner — Function
inner(ψ::TensorNetworkState, ϕ::TensorNetworkState; alg, kwargs...)

Compute the inner product ⟨ψ|ϕ⟩ between two TensorNetworkStates using the specified algorithm. The two states must have the same graph structure and physical indices on each site. For the squared norm of a single state, use norm_sqr(ψ; alg, kwargs...) instead.

Arguments

  • ψ::TensorNetworkState: The first tensor network state.
  • ϕ::TensorNetworkState: The second tensor network state.

Keyword Arguments

  • alg: The algorithm to use for the inner product calculation. Options include:
    • "exact": Exact contraction of the tensor network.
    • "bp": Belief propagation approximation.
    • "boundarymps": Boundary MPS approximation (requires env_maxdim).
    • "ctmrg": CTMRG approximation, on planar graphs (requires env_maxdim).
    • "loopcorrections": Loop corrections to belief propagation.
  • Extra kwargs for alg = "boundarymps":
    • env_maxdim::Integer: The bond dimension for the boundary MPS approximation.
    • partition_by: How to partition the graph for boundary MPS (default is "row").
    • cache_update_kwargs: Additional keyword arguments for updating the cache.
  • Extra kwargs for alg = "bp" or "loopcorrections":
    • cache_update_kwargs: Additional keyword arguments for updating the cache.
    • max_configuration_size: Maximum configuration size for loop corrections (only for "loopcorrections").
  • Extra kwargs for alg = "ctmrg":
    • env_maxdim::Integer: The bond dimension of the CTMRG environments.
    • cache_update_kwargs: Additional keyword arguments for updating the cache (by default only the free energy is converged).

Returns

  • The computed inner product as a scalar value.

Example

s = siteinds("S=1/2", g)
ψ = random_tensornetworkstate(ComplexF32, g, s; bond_dimension = 4)
ϕ = random_tensornetworkstate(ComplexF32, g, s; bond_dimension = 4)

# Exact inner product
ip_exact = inner(ψ, ϕ; alg = "exact")

# Belief propagation inner product
ip_bp = inner(ψ, ϕ; alg = "bp")

# Boundary MPS inner product with bond dimension 10
ip_bmps = inner(ψ, ϕ; alg = "boundarymps", env_maxdim = 10)

Entanglement Entropy

TensorNetworkQuantumSimulator.renyi_entropy — Function
renyi_entropy(ρ::AbstractMatrix, α::Real; normalize = true)

Compute the Rényi entropy of order α of a density matrix ρ.

The Rényi entropy is defined as

\[S_\alpha(\rho) = \frac{1}{1 - \alpha} \log \operatorname{tr}(\rho^\alpha)\]

The limit $\alpha \to 1$ recovers the von Neumann entropy $S = -\operatorname{tr}(\rho \log \rho)$, which is handled exactly.

Arguments

  • ρ: Density matrix as a plain Julia matrix.
  • α: Rényi index. Use α = 1 for von Neumann entropy, α = 2 for second Rényi entropy.

Keyword Arguments

  • normalize: If true (default), normalise ρ by its trace before computing the entropy.
source
renyi_entropy(a::Tensor, row_inds = ...; normalize = true, α = 1)

Compute the Rényi entropy of order α of a density matrix represented as a Tensor.

The tensor a is interpreted as a density matrix where unprimed indices are row indices and primed indices are column indices.

Arguments

  • a: Density matrix as a Tensor.
  • row_inds: The row (ket) indices. Defaults to all unprimed indices of a.

Keyword Arguments

  • normalize: If true (default), normalise by the trace.
  • α: Rényi index (default 1, i.e. von Neumann entropy).
source
renyi_entropy(bp_cache::BeliefPropagationCache, e::NamedEdge; α)

Compute the Rényi entropy of order α across the bond e using the BP messages stored in bp_cache.

This is an efficient single-edge computation that avoids constructing a full reduced density matrix. It is exact on trees and approximate on loopy graphs (subject to the quality of the BP fixed point). Requires the cache to already be updated.

Arguments

  • bp_cache: A converged BeliefPropagationCache.
  • e: The bond edge across which to compute the entanglement entropy.

Keyword Arguments

  • α: Rényi index. Use α = 1 for von Neumann entropy.
source

Message Passing

TensorNetworkQuantumSimulator.CTMRGCache — Type
CTMRGCache(network, env_maxdim::Integer; positions, projector = :svd)

Corner transfer matrix (CTMRG) environments for a tensor network on any planar graph. Every directed edge carries a message, as in belief propagation, and every inner face a ring of corners, each the contraction of a region of the network, with the cuts between them truncated to env_maxdim. The environment of a vertex or edge (incoming_messages) is its messages together with the corners around it. Call update on it before computing free energies or expectation values.

Arguments

  • network: A TensorNetwork, a TensorNetworkState (its norm network) or a form, on a planar graph.
  • env_maxdim::Integer: The bond dimension each cut is truncated to.

Keyword Arguments

  • positions: Vertex positions v => (x, y) defining the planar embedding (default: the vertex names, when they are coordinates). See planar_embedding.
  • projector::Symbol = :svd: How the cuts are truncated. :svd keeps the best approximation (a truncated SVD) of the two enlarged corners on either side of a cut. :eig (experimental) truncates all the cuts of a face together, keeping the dominant eigenvalues of the ring of its enlarged corners; it needs diagonal corners, so it is not available on every planar graph (e.g. kagome).

Returns

  • A CTMRGCache, whose update rules are fixed and certified exact at lossless env_maxdim (see ctmrg_rules).
source

update(cache::CTMRGCache; convergence = :messages, tolerance, maxiter = 30, verbose = false)

Update the corners and messages of a CTMRGCache until they converge.
